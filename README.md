# Der Baum — eine Reise in die Tiefe

Scrollytelling: Ein durchsichtiger Baum versinkt vom Wasserspiegel bis ins Challenger-Tief (10.935 m).
Eine Emotion pro Zone (Leichtigkeit → Stille → Einsamkeit → Ehrfurcht → Trost), echte Lichtphysik,
ab ~600 m sieht man den Baum nur im Lichtkegel einer ROV-Lampe. Inspiriert von „شجرة المشاعر“ (Amin Sabry).

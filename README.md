# Der Baum — eine Reise in die Tiefe

Scrollytelling-Seite: Ein Baum versinkt vom Wasserspiegel bis ins Challenger-Tief (10.935 m).
Echte Fotografie (Wikimedia Commons / NOAA, Public Domain & CC). Gefühle pro Tiefenzone, echte Tiefsee-Lebewesen mit Fakten.

Starten (kein Build, keine Abhängigkeiten):

```bash
python3 -m http.server 8765
```

Dann http://localhost:8765 öffnen.

| Datei | Inhalt |
|---|---|
| `index.html` | Struktur, Zonen, Lebewesen-Karten |
| `styles.css` | Gestaltung, Filmkorn, Responsive, Reduced Motion |
| `app.js` | Scroll→Tiefe, Ozean-Canvas, Baum-Ebene, HUD, Navigation, Modal |
| `data.js` | Gefühle (DE/AR) + wissenschaftliche Fakten |
| `assets/` | Echte Fotos (Baum + 12 Tiefsee-Lebewesen) |
